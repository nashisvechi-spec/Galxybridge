# Galaxy Bridge — только без отладки

## Новое · 0.8.0

Добавлены докачка файлов в обе стороны после обрыва, постоянная история
100 передач с повтором, диагностика связи, автозапуск Windows в трей и
экран телефона в отдельном окне ПК с жестами мышью. Показ экрана требует
системного подтверждения на телефоне. Прежний виджет и фоновая отправка доступны.

[Как пользоваться новыми функциями](docs/FEATURES_0.8.ru.md).
Это кандидат на релиз: исходники проверены, новая пара Setup/APK и реальные
ноутбук/S25 ещё требуют проверки.

## Подготовка к релизу · 0.7.37

Первое подключение теперь объясняется прямо в приложениях. При сохранённом
сопряжении используйте **Подключиться к сохранённому ПК** на телефоне; новый
QR требуется для нового сопряжения. Помощь объясняет проверку общей сети,
VPN и брандмауэра. Передача файлов не требует специальных возможностей.

В Windows на вкладке **Файлы → Телефон → ПК** доступны разрешение приёма,
папка назначения, изменение папки и отмена текущего приёма. Кнопки отправки,
управления и отмены учитывают состояние подключения. Удаление сопряжения
требует подтверждения. Android запоминает прокрутку вкладок и поясняет,
почему отправка недоступна. Выбор более 100 файлов отклоняется целиком;
часть подборки больше не отправляется незаметно для пользователя.

[Исследование, исправления и предложения](docs/RELEASE_REVIEW.ru.md).
Это кандидат на релиз: проверка реального ноутбука/S25 и сборка новой пары
установщик/APK остаются обязательными перед выпуском стабильной версии.

Windows **0.8.0**, Android **0.8.0**. При подключении Samsung DeX к монитору или
телевизору курсор и касания автоматически направляются на внешний дисплей.
Ручной выбор экрана не нужен, старые настройки выбора телефона игнорируются.
Если управление уже включено, оно возобновляется на DeX после отпускания
кнопок и клавиш. Без монитора используется экран смартфона.

После сборки — установщик **GalaxyBridge-Setup-0.8.0-x64.exe** для Windows
и отдельный **GalaxyBridgeLan.apk** для телефона.
Galaxy Files исключён из сборки; перенос файлов через край экрана удалён.
Обычная отправка, приём файлов и отдельный Windows-виджет доступны.
Переход курсора через край и Ctrl+Alt+F12 сохраняются.
Настройки разработчика и отладка не требуются.

После успешного получения файла с ПК Android показывает уведомление **Файл
получен с ПК** с именем файла. Нажатие открывает папку **Download/GalaxyBridge**.
Разрешите уведомления в приложении. Следующий полученный файл обновляет это
уведомление; отменённая или незавершённая передача его не показывает.

## Прозрачность виджета · Windows 0.7.35

**Настройки → Виджет передачи файлов → Прозрачность виджета**: ползунок от
0 до 80% и текущее значение в процентах. Изменения видны сразу и сохраняются
после закрытия виджета и перезапуска приложения. **Показать виджет** открывает
его для предпросмотра. По умолчанию — 0%, прежний внешний вид.

## Виджет передачи файлов · Windows 0.7.33

Виджет использует выбранный синий макет с бирюзовыми стрелками. Системной
рамки, заголовка окна и прямоугольной подложки нет; края и фон прозрачны.
Нажмите в центральной области, чтобы выбрать файлы, или перетащите их туда
из Проводника. Синий корпус перемещает виджет, круглый крестик закрывает его.
Закрытие виджета не завершает приложение и не отменяет текущую передачу.

Во время отправки появляются прогресс и **Отмена**. Без связи виджет показывает
состояние подключения и не принимает файлы. В подсказке центральной области —
телефон и результат последней отправки. Виджет работает при свёрнутом основном
окне, запоминает позицию и открывается через **Файлы** или меню значка в трее.
Клавиатура: **Tab / Shift+Tab**, **Enter / пробел**, **Esc** для закрытия.

## Звук уведомлений · Android 0.7.34

Новые категории получения файлов используют системный звук уведомлений.
Для уже установленного приложения: **Настройки → Включить звук уведомлений**.
Кнопка один раз заменяет беззвучную старую категорию и отправляет проверочное
уведомление. Обновление само по себе не сбрасывает выбранные настройки. Если
новая категория снова отключена или без звука, кнопка открывает её настройки.
При общем запрете уведомлений открываются настройки приложения.
Беззвучный режим, громкость уведомлений и «Не беспокоить» учитываются системой.
Постоянное уведомление подключения остаётся тихим.

## Уведомления · 0.7.32

На ПК получение файла показывает собственную карточку Galaxy Bridge в углу
экрана, в том числе при свёрнутом главном окне. Карточка не переключает фокус;
«Открыть папку» открывает папку последнего полученного файла. Следующий файл
обновляет карточку и её таймер. Это заменяет ненадёжный показ через значок в трее.

На Android приложение один раз запрашивает разрешение на уведомления при
открытии. В **Настройки → Разрешить уведомления** можно открыть системные
настройки после отказа или настроить категорию **Полученные файлы**. Статус
учитывает и разрешение приложения, и категорию. Новая категория создаётся с
высокой важностью; существующие настройки сохраняются. При обновлении со
старой версии включите всплывающий показ категории в системных настройках,
если статус сообщает «без всплывающего окна». Повторное получение снова
подаёт сигнал. На обеих платформах есть **Проверить уведомление** в настройках;
проверка не создаёт файл. Фоновая отправка с телефона не открывает окно
разрешений, а запрет уведомлений не мешает сохранению файла.

## Новый интерфейс · 0.7.31

Общий дизайн Windows и Android: карточки, синие действия, бирюзовая связь,
светлая и тёмная темы. По умолчанию оформление следует системе; ручной выбор
сохраняется в настройках.

В Windows — **Устройства / Управление / Файлы / Настройки**. На главном экране
статус связи, схема расположения устройств, управление и быстрые действия.
QR открывается отдельно. В файлах есть последние 10 завершённых передач
текущего сеанса; скорость курсора регулируется ползунком или числом.
Компактное окно файлов и виджет используют тот же дизайн.

На Android — нижние вкладки **Связь / Файлы / Настройки**. Переоформлены отправка,
текстовый буфер, QR-сканер и приём из файлового приложения. Контент прокручивается,
системные панели и клавиатура учитываются. После поворота выбранная вкладка
и черновик текста восстанавливаются. Фоновая отправка и пробуждение сохраняются.

[Дизайн и изображения интерфейса](docs/UI_DESIGN.ru.md).

## Пробуждение телефона

В версии **0.7.30** переход курсора через выбранный край ПК включает погасший
экран смартфона. Пробуждение также работает с кнопкой управления и
**Ctrl+Alt+F12**. Обновите Windows и Android; связь по Wi-Fi должна быть активна.
На телефоне нужна включённая служба Galaxy Bridge в специальных возможностях
либо разрешение **Поверх других приложений** для системной Bluetooth-мыши.

Курсор остаётся на ПК до включения экрана и готовности управления. PIN, пароль
и отпечаток сохраняются: заблокированный телефон разблокируйте обычным способом.
После разблокировки переход завершится, если курсор остаётся у выбранного края.
Ожидание длится до 15 секунд. Отведение курсора от края или повторное нажатие
кнопки/горячей клавиши отменяет переход. Пауза, разрыв связи и смена экрана на
DeX также отменяют ожидание. Подключённый DeX не будит экран смартфона.

## Подключение

1. В GitHub Actions запустите **Build Windows installer → Run workflow**.
   Сборка запускается только вручную.
2. Скачайте **GalaxyBridge-Windows-Setup** и **GalaxyBridgeLan-android**.
   Распакуйте архив артефакта Windows и запустите **GalaxyBridge-Setup-0.8.0-x64.exe**.
   Установщик создаст ярлык и запись для удаления программы. APK установите
   на телефон и откройте **Galaxy Bridge Wi-Fi**.
   [Установка и обновление Windows](docs/WINDOWS_INSTALLER.ru.md).
3. Подключите оба устройства к одной локальной сети. В Windows нажмите
   **Показать новый QR (2 минуты)**; при необходимости выберите адрес Wi-Fi.
4. На телефоне нажмите **Сканировать QR** внутри Galaxy Bridge, разрешите
   камеру и подтвердите ноутбук. Разрешите уведомления.
5. Разрешите приложению входящие соединения в брандмауэре Windows для
   используемой сети: TCP 38271 и UDP 38272.

Сопряжение по Wi-Fi запоминается. При обновлении Windows сохраняются прежние
настройки и сертификат: повторное сканирование QR не требуется. Устанавливайте
Android APK поверх установленного приложения с постоянной подписью.
[Правила обновления APK](docs/ANDROID_UPDATES.ru.md).

## Настройки курсора

В главном окне Windows рядом находятся:

- **Скорость курсора телефона / DeX** — 0,25–4×, обычная скорость 1×.
- **Задержка перехода курсора** — 0–2000 мс ожидания у выбранного края ПК перед
  входом на телефон или DeX. По умолчанию 350 мс (0,35 секунды); 0 мс убирает
  дополнительное ожидание. Переход проверяется таймером каждые 100 мс.

Обе настройки сохраняются. Рядом есть кнопки сброса. После изменения задержки
отведите курсор от края и подведите снова, чтобы началось новое ожидание.

## Два способа управления

| Способ | Требования | Поведение |
|---|---|---|
| Сенсорное управление по Wi-Fi | Служба Galaxy Bridge в специальных возможностях телефона | Касания, долгое нажатие, свайпы и перетаскивание; стрелка приложения |
| Системная мышь по Bluetooth (тест) | Windows 10 2004+; адаптер с Bluetooth LE Peripheral; системное сопряжение | Курсор Android, наведение, пять кнопок, выделение, обе оси колеса и физическая клавиатура |

Без Bluetooth используйте сенсорное управление по Wi-Fi. Оно не создаёт
системную мышь Android. Приложение запускает Bluetooth при открытии и выбирает
системную мышь автоматически, когда выбранный телефон подключился к HID.
Пока Bluetooth не готов, используется мышь приложения по Wi-Fi. Единственный
подключённый телефон выбирается автоматически; при нескольких выберите нужный.
Для первого сопряжения найдите ноутбук в Bluetooth телефона и подтвердите на
обоих устройствах. **Подключить Bluetooth (тест)** повторяет запуск после ошибки;
**Отключить Bluetooth** оставляет Wi-Fi до следующего включения или запуска.
Сохранённая запись сопряжения без активной HID-связи не включает системную мышь.
При смене способа текущий захват прекращается и удерживаемые клавиши отпускаются;
снова войдите на телефон горячей клавишей, кнопкой или через край экрана.

Нажмите **Управлять телефоном** или **Ctrl+Alt+F12**. Это же сочетание возвращает
управление на ПК. Вход через выбранный край экрана можно включить в окне.
Автоматический возврат через край телефона работает в обоих режимах. Для
Bluetooth установите APK **0.7.8**, подключите тот же телефон по QR и разрешите
**Поверх других приложений**. Вход через край включён по умолчанию для новых
настроек; существующий выбор сохраняется. При удержании кнопок или клавиш
возврат через край блокируется. Без Wi-Fi используйте Ctrl+Alt+F12. Раскладка физической клавиатуры
Bluetooth выбирается на телефоне. Файлы и общий буфер в обоих режимах идут по Wi-Fi.
[Подробности Bluetooth](docs/SYSTEM_MOUSE.ru.md).

GlideX использует отдельный драйвер Classic Bluetooth HID. Наш текущий BLE-режим
имеет другие требования к адаптеру; отсутствие BLE Peripheral не означает
общую несовместимость Bluetooth. Собственный Classic HID ещё не реализован.
[Результаты анализа Windows GlideX](docs/GLIDEX_WINDOWS.ru.md).

В **0.7.11** возвращена схема движения мыши из Windows **0.7.8** и соответствующего
Android **0.7.8**: передача по таймеру 16 мс, прежние пакеты движения и прямое
перемещение стрелки на телефоне. Обновите обе части приложения. Новый номер версии
позволяет установить APK поверх приложения с сохранением сопряжения и настроек.

В **0.7.12** обычный клик активирует элемент после отпускания левой кнопки.
Это исправляет путь выбора файла мышью в системном файловом окне: действие
больше не ограничено щелчками короче 32 мс. Перетаскивание начинается при движении
за порог касания. Неподвижное удержание распознаётся перед отправкой жеста,
поэтому появления выделения может потребоваться ждать около секунды при
стандартных настройках Android. Схема свободного движения из 0.7.8 сохранена.

## Колёсико и возврат на ПК

Обновите Windows и APK до **0.7.25**. При управлении по Wi-Fi наведите курсор
на страницу PDF: **Ctrl + колёсико** увеличивает и уменьшает масштаб жестом
двух пальцев. Для масштабирования одним колёсиком включите в Windows
**Масштабировать колёсиком по Wi-Fi**. Настройка сохраняется. Просмотрщик должен
поддерживать масштабирование двумя пальцами. Без настройки колесо прокручивает
страницу; для Bluetooth поведение определяет приложение Android.

Для возврата на ПК двигайте курсор к краю телефона, обращённому к компьютеру.
Возврат использует прежние проверки направления, свежести движения и положения
курсора из 0.7.8. При удержании кнопок или клавиш переход блокируется. Горячая
клавиша **Ctrl+Alt+F12** остаётся доступна.

## Текст и файлы

Включите **Общий текстовый буфер** в Windows, а на телефоне — **Разрешить переходы мыши и общий
буфер** и **Поверх других приложений**. Текст, скопированный на ПК во время связи,
передаётся в буфер телефона. Текст телефона читается при возврате управления
на ПК; вставляйте обычным Ctrl+V. Это не постоянное фоновое чтение буфера Android.
Поддерживаются текст и ссылки до 16 КБ UTF-8.

Файлы можно перетащить в окно Windows или отправить из **Окно файлов: отправка
и приём**. На телефоне используйте отправку файлов либо **Поделиться → Galaxy
Bridge Wi-Fi**: после выбора Galaxy Bridge подготовка и отправка начинаются
автоматически в фоне, без дополнительной кнопки и без открытия окна Galaxy Bridge.
После проверки и сохранения файла на ПК появляется уведомление «Файл получен с телефона»
с именем файла; нажмите его, чтобы открыть папку приёма. Окно ручной отправки
в приложении по-прежнему показывает прогресс и отмену. Папки не поддерживаются; до 2 ГБ на файл. На телефоне файлы
сохраняются в Download/GalaxyBridge, на ПК по умолчанию — Downloads/GalaxyBridge.

Сворачивание прячет окно в область уведомлений; двойной щелчок по значку
возвращает его. Закрытие окна или **Выход** в меню значка завершает приложение.
Пауза останавливает управление и соединение по Wi-Fi, сохраняя сопряжение.

## Сборка из исходников

.NET 8 SDK, Windows SDK и PowerShell 7; Android SDK API 35 / build-tools 35.0.0,
JDK 17. Постоянный ключ подписи должен соответствовать android/signing-cert.sha256.

```powershell
python scripts/check_sources.py
dotnet run --project tests/GalaxyBridge.Core.Tests -c Release
dotnet run --project tests/GalaxyBridge.LanTls.Tests -c Release
./scripts/Test-LanProtocol.ps1
dotnet publish src/GalaxyBridge.Windows -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/GalaxyBridge
./scripts/Build-LanCompanion.ps1 -Destination artifacts/GalaxyBridge -VersionCode 100500
# Скопируйте инструкции, LICENSE, THIRD_PARTY_NOTICES.md, licenses/ и docs/ в папку публикации.
./scripts/Build-WindowsInstaller.ps1
```

Версию APK задавайте больше установленной. Готовая сборка содержит
установщик Windows и один отдельный Android APK — GalaxyBridgeLan.apk.
Для локальной упаковки Windows нужен Inno Setup 6.
Исходники Galaxy Files остаются в репозитории, но в активный workflow и пакет
приложения не входят.
