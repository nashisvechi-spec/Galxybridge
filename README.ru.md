# Galaxy Bridge — только без отладки

Windows **0.7.6**, Android **0.7.7**. Приложение сразу открывает подключение
по локальной сети. Настройки разработчика, USB-отладка и беспроводная отладка
не требуются. В проекте осталась одна версия приложения.

## Подключение

1. В GitHub Actions запустите **Build Windows portable → Run workflow**.
   Сборка запускается только вручную.
2. Скачайте **GalaxyBridge-win10-x64** и **GalaxyBridgeLan-android**.
   Распакуйте ZIP, запустите GalaxyBridge.exe. Установите GalaxyBridgeLan.apk
   на телефон и откройте **Galaxy Bridge Wi-Fi**.
3. Подключите оба устройства к одной локальной сети. В Windows нажмите
   **Показать новый QR (2 минуты)**; при необходимости выберите адрес Wi-Fi.
4. На телефоне нажмите **Сканировать QR** внутри Galaxy Bridge, разрешите
   камеру и подтвердите ноутбук. Разрешите уведомления.
5. Разрешите приложению входящие соединения в брандмауэре Windows для
   используемой сети: TCP 38271 и UDP 38272.

Сопряжение по Wi-Fi запоминается. При обновлении Windows сохраняются прежние
настройки и сертификат: повторное сканирование QR не требуется. Устанавливайте
Android APK поверх установленного приложения с постоянной подписью.
[Правила обновления APK](docs/ANDROID_UPDATES.ru.md).

## Два способа управления

| Способ | Требования | Поведение |
|---|---|---|
| Сенсорное управление по Wi-Fi | Служба Galaxy Bridge в специальных возможностях телефона | Касания, долгое нажатие, свайпы и перетаскивание; стрелка приложения |
| Системная мышь по Bluetooth (тест) | Windows 10 2004+; адаптер с Bluetooth LE Peripheral; системное сопряжение | Курсор Android, наведение, пять кнопок, выделение, обе оси колеса и физическая клавиатура |

Без Bluetooth используйте сенсорное управление по Wi-Fi. Оно не создаёт
системную мышь Android. Приложение запускает Bluetooth при открытии и выбирает
системную мышь автоматически, когда выбранный телефон подключился к HID.
Пока Bluetooth не готов, используется мышь приложения по Wi-Fi. Единственный
подключённый телефон выбирается автоматически; при нескольких выберите нужный.
Для первого сопряжения найдите ноутбук в Bluetooth телефона и подтвердите на
обоих устройствах. **Подключить Bluetooth (тест)** повторяет запуск после ошибки;
**Отключить Bluetooth** оставляет Wi-Fi до следующего включения или запуска.
Сохранённая запись сопряжения без активной HID-связи не включает системную мышь.
При смене способа текущий захват прекращается и удерживаемые клавиши отпускаются;
снова войдите на телефон горячей клавишей, кнопкой или через край экрана.

Нажмите **Управлять телефоном** или **Ctrl+Alt+F12**. Это же сочетание возвращает
управление на ПК. Вход через выбранный край экрана можно включить в окне.
Автоматический возврат через край телефона работает в сенсорном режиме;
для Bluetooth пока используйте горячую клавишу. Раскладка физической клавиатуры
Bluetooth выбирается на телефоне. Файлы и общий буфер в обоих режимах идут по Wi-Fi.
[Подробности Bluetooth](docs/SYSTEM_MOUSE.ru.md).

## Текст и файлы

Включите **Общий текстовый буфер** в Windows, а на телефоне — **Разрешить общий
буфер** и **Поверх других приложений**. Текст, скопированный на ПК во время связи,
передаётся в буфер телефона. Текст телефона читается при возврате управления
на ПК; вставляйте обычным Ctrl+V. Это не постоянное фоновое чтение буфера Android.
Поддерживаются текст и ссылки до 16 КБ UTF-8.

Файлы можно перетащить в окно Windows или отправить из **Окно файлов: отправка
и приём**. На телефоне используйте отправку файлов либо **Поделиться → Galaxy
Bridge Wi-Fi**. Папки не поддерживаются; до 2 ГБ на файл. На телефоне файлы
сохраняются в Download/GalaxyBridge, на ПК по умолчанию — Downloads/GalaxyBridge.

Сворачивание прячет окно в область уведомлений; двойной щелчок по значку
возвращает его. Закрытие окна или **Выход** в меню значка завершает приложение.
Пауза останавливает управление и соединение по Wi-Fi, сохраняя сопряжение.

[Полная инструкция](docs/NATIVE_WIFI.ru.md) · [Проверки](docs/TESTING.md)

## Сборка из исходников

.NET 8 SDK, Windows SDK и PowerShell 7; Android SDK API 35 / build-tools 35.0.0,
JDK 17. Постоянный ключ подписи должен соответствовать android/signing-cert.sha256.

```powershell
python scripts/check_sources.py
dotnet run --project tests/GalaxyBridge.Core.Tests -c Release
dotnet run --project tests/GalaxyBridge.LanTls.Tests -c Release
./scripts/Test-LanProtocol.ps1
dotnet publish src/GalaxyBridge.Windows -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/GalaxyBridge
./scripts/Build-LanCompanion.ps1 -Destination artifacts/GalaxyBridge -VersionCode 100500
```

Версию APK задавайте больше установленной. Готовая сборка содержит один APK —
GalaxyBridgeLan.apk. Историческая версия с отладкой доступна только в истории Git.
