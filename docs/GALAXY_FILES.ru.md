# Galaxy Files · 0.1.0

Отдельный Android-файловый менеджер в общем репозитории GalaxyBridge.
Пакет: `com.galaxybridge.files`; исходники: `android/files`; APK: `GalaxyFiles.apk`.
Работает на Android 13 и новее. GalaxyBridge Wi-Fi устанавливается отдельно;
для обычных файловых операций подключение к ПК не требуется.

## Установка и доступ

1. Запустите вручную **Build Windows portable** в GitHub Actions.
2. Скачайте `GalaxyFiles-android` и установите `GalaxyFiles.apk`.
3. Откройте меню ⋮ → **Доступ к файлам** и разрешите управление файлами.
4. Для передачи на ПК обновите также `GalaxyBridgeLan.apk` 0.7.21 из того же запуска.
   Оба APK подписываются существующим ключом проекта; новые ключи не создаются.
5. В GalaxyBridge Wi-Fi выполните обычное сопряжение с ПК и включите управление.

В комплект Windows добавлены два отдельных APK. У Galaxy Files своё имя,
значок, хранилище настроек и экран запуска; оно не заменяет GalaxyBridge.

## Первая версия

- Папки внутренней общей памяти и быстрые переходы в Download, DCIM и Documents.
- Поиск по имени в текущей папке, папки в начале списка, скрытые файлы по настройке.
- Выделение нескольких элементов, создание папок, переименование, копирование,
  перемещение и удаление папок вместе с содержимым.
- При копировании совпадающее имя получает суффикс; существующие файлы не затираются.
  Неудачная копия не публикуется под итоговым именем. Символические ссылки отклоняются.
- Открытие файлов установленными приложениями и системное «Поделиться».
- Кнопка **На ПК** открывает существующий экран передачи GalaxyBridge с известными
  файлами, без выбора в Samsung «Мои файлы».

Пальцем: нажатие открывает, галочка выделяет, удержание открывает действия.
Мышью: один клик выделяет, двойной открывает, правый показывает действия.

## Перетаскивание мышью по Wi-Fi

1. Откройте Galaxy Files на телефоне, подключённом к Windows GalaxyBridge.
2. Выделите файлы либо зажмите один файл и начните движение мышью.
3. Тяните к краю со стороны ПК, продолжая удерживать левую кнопку.
4. Пока файлы копируются во временное хранилище ПК, кнопка остаётся зажатой.
   Следите за текстом состояния внизу. Большие файлы требуют времени подготовки.
5. После перехода курсора в Windows отпустите файлы в нужной папке или на рабочем столе.
   Esc отменяет действие в Windows. Оригиналы на телефоне сохраняются.

Если отпустить кнопку до перехода курсора, подготовка отменяется. При потере
связи, блокировке телефона или уходе из менеджера незавершённый жест сбрасывается.
Передача использует существующие ограничения протокола: до 100 файлов,
до 2 ГБ на файл; для подборки перетаскивания действует лимит Windows 2 ГБ.
Папки на ПК пока не передаются; их можно копировать и перемещать локально.

Настоящая Bluetooth-мышь использует обычное Android-перетаскивание с URI.
Для него приём у края экрана включается в GalaxyBridge. Этот маршрут зависит
от системных событий Android и отдельно проверяется на устройстве.

## Архитектура и дальнейшие функции

`FilesActivity` отвечает за интерфейс; `FileOps` — за локальные операции;
`FilePointer` — за выбор/двойной клик/намерение перетаскивания;
`SharedFilesProvider` выдаёт доступ только на чтение к отдельным файлам.

`FilesBridgeService` находится в приложении GalaxyBridge и защищён разрешением
уровня signature. Менеджер связывается с ним через Messenger. Сервис проверяет
UID и подпись отправителя. У приложения Galaxy Files нет разрешения INTERNET;
соединение и сопряжение остаются в GalaxyBridge, пароли между приложениями
не передаются. Управление направляется в менеджер только при его активном
окне; диалоги используют обычное управление через специальные возможности.

Ограничения первой версии: только общая внутренняя память, без облаков, SD/USB,
архивов, миниатюр и корзины. Android/data, Android/obb и закрытые данные
приложений недоступны. Локальные операции выполняются в фоне интерфейса,
но не оформлены как отдельная служба для продолжения после закрытия процесса.
Удаление требует подтверждения и необратимо. При частичной ошибке пакетной
операции показывается число уже обработанных элементов.

## Проверка

`scripts/Test-Files.ps1` компилирует и запускает JVM-тесты файловых операций и
мыши без Android: обход пути, закрытые папки, сохранность оригинала, совпадения
имён, незавершённое копирование, копирование дерева, перемещение, Unicode,
поиск, удаление, двойной клик, отмена и единственный запуск подготовки.
`scripts/Build-Files.ps1` собирает APK средствами Android SDK 35.

Сценарии на S25 перед использованием: разрешение общей памяти; открытие PDF;
копирование с совпадением имён; несколько выделенных файлов; отправка кнопкой;
перетаскивание маленького и большого файла; отпускание до окончания подготовки;
потеря Wi-Fi при подготовке; правый клик в диалоге; уход в другое приложение.
Компиляция и JVM-тесты не заменяют эти проверки на реальном телефоне.

Проверено при добавлении: обе Android-программы компилируются против SDK 35;
ресурсы, DEX, упаковка APK и выравнивание ZIP проходят проверку для обеих программ.
Прошли 41 проверка файлового менеджера и 1062 проверки существующих Android-хелперов.
Локальная проверочная упаковка выполнена без подписи; устанавливаемые APK с
сохранённым ключом создаёт ручной workflow. Подписанная сборка в Actions и
перетаскивание на реальном телефоне в рамках этой проверки не запускались.
