# Galaxy Files · 0.2.3

Отдельный Android-файловый менеджер в общем репозитории GalaxyBridge.
Пакет: `com.galaxybridge.files`; исходники: `android/files`; APK: `GalaxyFiles.apk`.
Работает на Android 13 и новее. GalaxyBridge Wi-Fi устанавливается отдельно;
для обычных файловых операций подключение к ПК не требуется.

## Работа на дисплее DeX (0.2.3 / GalaxyBridge 0.7.24)

В Galaxy Bridge Wi-Fi выберите внешний экран через **Экран управления: телефон /
DeX**, затем откройте Galaxy Files на том же дисплее. Управление файловым менеджером
проверяет номер дисплея: координаты монитора не передаются окну на телефоне.
Начатое в окне нажатие сохраняет принадлежность этому окну, пока кнопка удерживается;
файл можно тянуть за пределы небольшого окна к краю монитора. При переносе окна
на другой дисплей, смене захвата или закрытии приложения жест сбрасывается.
Перенос через край по-прежнему включается отдельной галочкой Windows.

## Исправление переноса через край в 0.2.1 / GalaxyBridge 0.7.22

Обновите оба APK и Windows EXE из одного нового запуска сборки. Исправлен
пакет отмены, который мог разрывать Wi-Fi вместо отмены одной передачи.
Краткая недоступность окна файлового менеджера больше не считается выходом
из приложения. Если файл уже подготовлен, но мышь двигалась вдоль края или
обратно внутрь экрана, продолжите движение к ПК, удерживая левую кнопку.

Шкала приёма на ПК показывает подготовку во временном хранилище. Дождитесь
перехода курсора в Windows и только затем отпустите файл в нужной папке.
Раннее отпускание отменяет подготовку; следующую попытку можно начать без
повторного подключения. Поведение на физическом телефоне требует проверки.

## Интерфейс 0.2.0

По мотивам расположения блоков Samsung «Мои файлы»: светлая главная страница,
скруглённые секции, четыре недавних файла, категории в сетке 3 × 2 и карточка
внутренней памяти с индикатором заполнения. Значки нарисованы отдельно для проекта.
Категории: изображения, видео, аудио, документы, загрузки и APK.

В папке доступны список и сетка, сортировка по имени, дате и размеру.
Слева в списке — миниатюра или значок типа, рядом — имя, дата и размер.
Для фото и видео миниатюры загружаются в фоне, с ограниченными очередью и кэшем;
у видео есть отметка воспроизведения. PDF, офисные файлы и архивы имеют разные
значки; просмотр страниц PDF и распаковка архивов пока не добавлены.
Нижняя панель действий появляется при выделении или наличии файлов для вставки.

Категории используют индекс Android и дополнительный ограниченный обход обычных
медиапапок. «Недавние» сортируются по времени изменения. Индекс может обновляться
с задержкой; просмотр внутренней памяти всегда показывает файлы самой папки.
Поиск с главной страницы идёт по подборке недавних файлов, в папке — по её содержимому.
В категориях показывается до 2000 элементов; переход в память доступен для полного просмотра.

## Исправление открытия в 0.1.1

В 0.1.0 фокусируемая галочка внутри строки блокировала обычные нажатия списка:
папки не открывались, а нажатие на файл не запускало просмотр. Теперь галочка
выделяет элемент, а строка открывает его. Выделение других элементов больше
не мешает открытию папки назначения для копирования или перемещения.
У строк есть явные обработчики нажатия и удержания, доступные также специальным
возможностям Android. Мышью один клик по-прежнему выделяет, двойной открывает.

Исправление проверено 10 регрессионными тестами интерфейса на Android SDK 35
через Robolectric: реальные события DOWN/UP проходят через Activity и ListView,
проверяется открытие папок, создание Intent просмотра PDF с правом чтения,
нажатие на галочку, открытие при выделении, обычный и Wi-Fi двойной клик,
действие доступности и чтение файла с пробелами/кириллицей во вложенной папке.
На исходной 0.1.0 тесты обычного открытия воспроизводили сбой.

Тестовая среда имитирует разрешение памяти, таблицу MIME и отсутствующий в
Robolectric native-getter координат мыши; внешний PDF-просмотрщик и физический
телефон эти тесты не запускают. Проверки выполняются перед упаковкой APK в
ручном workflow; отдельно их можно запустить командой
`mvn -B -f tests/android-files-ui/pom.xml test` (JDK 17 и Maven).

## Установка и доступ

1. Запустите вручную **Build Windows portable** в GitHub Actions.
2. Скачайте `GalaxyFiles-android` и установите `GalaxyFiles.apk`.
3. Откройте меню ⋮ → **Доступ к файлам** и разрешите управление файлами.
4. Для передачи на ПК обновите также `GalaxyBridgeLan.apk` 0.7.24 из того же запуска.
   Оба APK подписываются существующим ключом проекта; новые ключи не создаются.
5. В GalaxyBridge Wi-Fi выполните обычное сопряжение с ПК и включите управление.

В комплект Windows добавлены два отдельных APK. У Galaxy Files своё имя,
значок, хранилище настроек и экран запуска; оно не заменяет GalaxyBridge.

## Первая версия

- Папки внутренней общей памяти и быстрые переходы в Download, DCIM и Documents.
- Поиск по имени в текущей папке, папки в начале списка, скрытые файлы по настройке.
- Выделение нескольких элементов, создание папок, переименование, копирование,
  перемещение и удаление папок вместе с содержимым.
- При копировании совпадающее имя получает суффикс; существующие файлы не затираются.
  Неудачная копия не публикуется под итоговым именем. Символические ссылки отклоняются.
- Открытие файлов установленными приложениями и системное «Поделиться».
- Кнопка **На ПК** открывает существующий экран передачи GalaxyBridge с известными
  файлами, без выбора в Samsung «Мои файлы».

Пальцем: нажатие открывает, удержание включает выделение; кнопка «Выделить» показывает галочки.
Действия доступны на нижней панели и в меню «Ещё».
Мышью: один клик выделяет, двойной открывает, правый показывает действия.

## Перетаскивание мышью по Wi-Fi

1. Откройте Galaxy Files на телефоне, подключённом к Windows GalaxyBridge.
2. Выделите файлы либо зажмите один файл и начните движение мышью.
3. В Windows включите **Перенос файлов с телефона через край**, затем тяните к краю со стороны ПК, продолжая удерживать левую кнопку.
4. Пока файлы копируются во временное хранилище ПК, кнопка остаётся зажатой.
   Следите за текстом состояния внизу. Большие файлы требуют времени подготовки.
5. После перехода курсора в Windows отпустите файлы в нужной папке или на рабочем столе.
   Esc отменяет действие в Windows. Оригиналы на телефоне сохраняются.

Если отпустить кнопку до перехода курсора, подготовка отменяется. При потере
связи, блокировке телефона или уходе из менеджера незавершённый жест сбрасывается.
Передача использует существующие ограничения протокола: до 100 файлов,
до 2 ГБ на файл; для подборки перетаскивания действует лимит Windows 2 ГБ.
Папки на ПК пока не передаются; их можно копировать и перемещать локально.

Настоящая Bluetooth-мышь использует обычное Android-перетаскивание с URI.
Для него приём у края экрана включается в GalaxyBridge. Этот маршрут зависит
от системных событий Android и отдельно проверяется на устройстве.

## Архитектура и дальнейшие функции

`FilesActivity` отвечает за интерфейс; `FileOps` — за локальные операции;
`FilePointer` — за выбор/двойной клик/намерение перетаскивания;
`FileCatalog` — за подборки, `FileKind` и `FileArtwork` — за типы и значки,
`ThumbnailLoader` — за ограниченную фоновую загрузку миниатюр;
`SharedFilesProvider` выдаёт доступ только на чтение к отдельным файлам.

`FilesBridgeService` находится в приложении GalaxyBridge и защищён разрешением
уровня signature. Менеджер связывается с ним через Messenger. Сервис проверяет
UID и подпись отправителя. У приложения Galaxy Files нет разрешения INTERNET;
соединение и сопряжение остаются в GalaxyBridge, пароли между приложениями
не передаются. Управление направляется в менеджер только при его активном
окне; диалоги используют обычное управление через специальные возможности.

Ограничения первой версии: только общая внутренняя память, без облаков, SD/USB,
распаковки архивов и корзины. Android/data, Android/obb и закрытые данные
приложений недоступны. Локальные операции выполняются в фоне интерфейса,
но не оформлены как отдельная служба для продолжения после закрытия процесса.
Удаление требует подтверждения и необратимо. При частичной ошибке пакетной
операции показывается число уже обработанных элементов.

## Проверка

`scripts/Test-Files.ps1` компилирует и запускает JVM-тесты файловых операций и
мыши без Android: обход пути, закрытые папки, сохранность оригинала, совпадения
имён, незавершённое копирование, копирование дерева, перемещение, Unicode,
поиск, удаление, двойной клик, отмена и единственный запуск подготовки.
`scripts/Build-Files.ps1` собирает APK средствами Android SDK 35.

Сценарии на S25 перед использованием: разрешение общей памяти; открытие PDF;
копирование с совпадением имён; несколько выделенных файлов; отправка кнопкой;
перетаскивание маленького и большого файла; отпускание до окончания подготовки;
потеря Wi-Fi при подготовке; правый клик в диалоге; уход в другое приложение.
Компиляция и JVM-тесты не заменяют эти проверки на реальном телефоне.

Проверено при добавлении: обе Android-программы компилируются против SDK 35;
ресурсы, DEX, упаковка APK и выравнивание ZIP проходят проверку для обеих программ.
Прошли 41 проверка файлового менеджера и 1062 проверки существующих Android-хелперов.
Локальная проверочная упаковка выполнена без подписи; устанавливаемые APK с
сохранённым ключом создаёт ручной workflow. Подписанная сборка в Actions и
перетаскивание на реальном телефоне в рамках этой проверки не запускались.

Проверка 0.2.0: прошли 12 UI-регрессий (включая переход с главной в категорию
и открытие файла в сетке) и 3 проверки представления: типы файлов, фильтрация
каталога, фоновая миниатюра и повторное назначение строки другому файлу.
В Robolectric привязка ImageDecoder к файлу требует настоящего Android;
в тесте миниатюр только эта привязка заменена декодированием PNG из потока.
Системный декодер видео проверяется на телефоне. Дополнительно проверены
41 файловая/мышиная проверка, компиляция SDK 35, ресурсы, DEX и zipalign
для APK 0.2.0. Главная, список и сетка отрисованы для проверки компоновки;
подписанная сборка Actions и установка на S25 не запускались.
