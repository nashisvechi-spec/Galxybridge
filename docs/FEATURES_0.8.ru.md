# Galaxy Bridge 0.8.0

Добавлены все пять функций из плана развития 0.7.37. Для новых возможностей
обновите Windows и Android до одной версии. Старые приложения продолжают
использовать прежний протокол передачи.

| Функция | Где находится | Как работает |
| --- | --- | --- |
| Докачка файлов в обе стороны | Обычная отправка, виджет и Android «Поделиться» | Перед отправкой вычисляется SHA‑256. После обрыва в текущей отправке приложение ждёт связь до двух минут и продолжает с сохранённого байта; до пяти попыток. Готовый файл проходит полную проверку. |
| Постоянная история | Windows: Файлы → Открыть историю; Android: Файлы → История передач | Хранятся последние 100 результатов, включая ошибки и отмены. Можно открыть полученный файл и повторить отправку. Очистка истории сохраняет сами файлы. |
| Диагностика | Windows: Устройства → Проверить подключение; Android: Настройки → Проверить подключение | Показывает состояние связи, сети и разрешений. Windows проверяет запись в папку приёма; Android — доступ управления, буфера и уведомлений. Отчёт можно скопировать. |
| Автозапуск Windows | Настройки → Запуск Windows | Галочка добавляет запуск текущего пользователя в трей при входе в Windows. Выбор сохраняется при обновлении установщика; удаление приложения убирает запись автозапуска. |
| Экран телефона на ПК | Windows: Устройства → Экран телефона на ПК | На телефоне появляется запрос. Откройте уведомление или Настройки → Экран телефона на ПК → Разрешить показ экрана и подтвердите системный диалог Android. |

## Докачка и история

Автоматическое продолжение относится к текущей очереди отправки. Новое
сопряжение с другим устройством останавливает её. После закрытия приложения
или истечения ожидания используйте повтор в истории: это новая отправка.
На Android доступ к исходному URI зависит от файлового приложения; при утрате
доступа выберите файл снова. Системный выбор документов сохраняет доступ,
когда источник разрешает это делать. Отправка через «Поделиться» остаётся фоновой.

Частичные файлы лежат в служебном кэше, получатель видит файл только после
проверки SHA‑256. Завершённая операция запоминается: потеря последнего
подтверждения не создаёт второй файл. Старые служебные записи очищаются
при последующих передачах, срок хранения — 24 часа, число записей ограничено.
При отмене без связи удалённый частичный кэш может сохраниться до очистки.
Прежнее ограничение — до 100 файлов, до 2 ГБ каждый.

Повтор из истории отправляет файл текущему подключённому устройству. Исходник
должен существовать и быть доступен. Windows хранит журнал в профиле приложения,
Android — в своих настройках; очистка данных приложения удалит его историю.

## Просмотр экрана и управление

Окно ПК показывает основной экран телефона. Левый клик — нажатие,
перетаскивание — жест, колесо — прокрутка. После выбора поля можно печатать
с клавиатуры ПК, использовать Ctrl+V, Ctrl+A, Enter, Backspace и Delete.
Защищённые поля заполняйте на самом телефоне. Для жестов включите Galaxy Bridge
в специальных возможностях Android. Нажатия учитывают поворот изображения,
поля вокруг него и текущую версию размеров кадра. Закрытие окна завершает показ;
на телефоне доступна остановка в постоянном уведомлении и системном индикаторе.

Каждый новый сеанс требует подтверждения Android. Разрыв связи прекращает
захват; после подключения потребуется новый запрос. Запоздалое подтверждение
закрытого запроса игнорируется. Окно просмотра работает независимо от свёрнутого
главного окна Windows.

Первая реализация передаёт JPEG-кадры по существующему TLS-соединению: до 4
кадров/с, длинная сторона до 960 пикселей. Это режим для интерфейса и документов.
Звуковой поток не передаётся. Для плавного видео понадобится отдельный этап
с аппаратным видеокодеком. Во время передачи файлов кадры и жесты приостанавливаются,
чтобы не мешать передаче. После неё просмотр продолжается.

Внешний экран DeX управляется существующим способом. Новый просмотр захватывает
основной экран телефона; защищённые системные окна и содержимое с запретом
захвата подчиняются ограничениям Android.

## Проверка и выпуск

Проверены 2559 условия ядра и 96 Android-теста. Есть реальные TLS-тесты докачки,
продолжения с нужного байта, повторного подтверждения готового файла и потока
кадров. Android-тесты проверяют отказ, принятие и отмену согласия, поздний ответ,
историю, докачку и прежние сценарии. Исходники обеих платформ компилируются.

Новые Setup/APK ещё не собраны. Захват настоящих кадров MediaProjection,
инъекция жестов на S25, Windows UI и автозапуск после входа в систему требуют
проверки на устройствах. Поэтому версия остаётся кандидатом на релиз.
Сборка и установочные проверки доступны в прежнем ручном workflow GitHub Actions.

Основания реализации:
[Android MediaProjection](https://developer.android.com/media/grow/media-projection),
[Windows Run](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys),
[Inno Setup Registry](https://jrsoftware.org/ishelp/topic_registrysection.htm).
