# Статус проверки исходного архива

Дата подготовки: 9 октября 2026. Версия проекта: 0.1.0.

| Проверка | Статус |
| --- | --- |
| JSON/XML, ссылки между проектами, структура исходного пакета | Проверено скриптом check_sources.py |
| Согласование версии и SHA-256 backend в манифесте, клиенте и скрипте | Проверено по исходникам и метаданным официального релиза |
| YAML workflow и ручной триггер без push/PR | Проверено при подготовке |
| Наличие исходников, инструкций и лицензий в ZIP; отсутствие EXE/DLL/JAR | Проверено при упаковке |
| Компиляция C# и запуск тестов C# | Не выполнялись |
| Скачивание/запуск бинарников backend | Не выполнялись |
| Работа Windows hooks, UHID, буфера на HP + S25 | Не проверена |

Скрипт проверки исходного пакета использует стандартную библиотеку Python,
не скачивает зависимости и не запускает сборку. Он не заменяет компилятор.

В проект добавлены переносимые C# проверки пакетного формата, Unicode,
модификаторов клавиатуры, rollover, разбиения перемещения мыши, сетевых
адресов, состояний ADB и чтения фрагментированного потока. Их запуск входит
в **ручной** workflow, перед публикацией EXE.

Сборка приложения и workflow при подготовке этого архива не запускались
согласно запросу пользователя. Для проверки железа используйте TESTING.md.
