# Статус проверки исходников

Дата подготовки: 9 октября 2026. Версия проекта: 0.2.1.

В версии 0.2.0 пользователь сообщил о `WINDOW_IllegalStateException` на S25.
Полный текст исключения и стек та версия не сохраняла, поэтому точное место
сбоя на One UI пока не установлено. Версия 0.2.1 исправляет подготовку
приложения shell и оконного контекста; журнал теперь сохраняет этап, сообщение
и ограниченный стек исключения. Работу этого исправления на S25 ещё нужно
проверить после ручной сборки.

| Проверка | Статус |
| --- | --- |
| JSON/XML, ссылки между проектами, структура исходного пакета | Проверено скриптом check_sources.py |
| Согласование версии и SHA-256 backend в манифесте, клиенте и скрипте | Проверено по исходникам и метаданным официального релиза |
| YAML workflow и ручной триггер без push/PR | Проверено при подготовке |
| Структура новых C#/Java-исходников и включение компонента в ручной workflow | Проверено без компиляции |
| Компиляция C# и запуск тестов C# | Не выполнялись |
| Компиляция Java/D8 компонента автовозврата | Не выполнялась |
| Скачивание/запуск бинарников backend | Не выполнялись |
| Работа Windows hooks, UHID, буфера на HP + S25 | Не проверена |
| Автовозврат, временное окно и разрешения на One UI | Не проверены на устройстве |

Скрипт проверки исходного пакета использует стандартную библиотеку Python,
не скачивает зависимости и не запускает сборку. Он не заменяет компилятор.

В проект добавлены переносимые C# проверки пакетного формата, Unicode,
модификаторов клавиатуры, rollover, разбиения перемещения мыши, сетевых
адресов, состояний ADB и чтения фрагментированного потока. Их запуск входит
в **ручной** workflow, перед публикацией EXE. Добавлены проверки парсинга
координат края, четырёх расположений телефона, устаревших кадров и движения,
идентификатора захвата, запрета возврата при удержании кнопок/клавиш и
соответствия позиции на мониторах с отрицательными координатами. Эти C# тесты
в текущей среде не запускались: .NET SDK отсутствует.

Сборка приложения и workflow при подготовке этих изменений не запускались
согласно запросу пользователя. Для проверки железа используйте TESTING.md.
