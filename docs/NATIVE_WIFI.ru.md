# Galaxy Bridge без отладки — Windows 0.7.10 / Android 0.7.10

Это единственная активная версия. Основной экран сразу открывает локальное
подключение. Установка и первые шаги описаны в [README](../README.ru.md).

## Сопряжение и обновления

Оба устройства должны находиться в одной доступной локальной сети. Выберите
адрес сетевой карты Windows и покажите новый QR. Он действует две минуты.
Сканируйте кнопкой **Сканировать QR** в Galaxy Bridge Wi-Fi; после распознавания
подтвердите название ноутбука и адрес. Камера телефона вне приложения для этого
сопряжения не используется. При отказе можно сканировать заново.

Разрешите входящие TCP 38271 и UDP 38272 в брандмауэре Windows для вашей сети.
В гостевой сети с изоляцией клиентов устройства могут не видеть друг друга.
Строка состояния показывает этап подключения и ошибку. При смене общей сети
телефон ищет сохранённый ноутбук и проверяет прежний сертификат.

QR содержит адрес, идентификатор, отпечаток TLS-сертификата и одноразовый секрет.
Телефон проверяет сертификат и подтверждение пользователя. Постоянные данные
Windows защищены DPAPI текущего пользователя. Сертификат не добавляется в
доверенные корневые центры. **Забыть телефон** отзывает постоянный токен;
затем покажите новый QR.

Обновление Windows не меняет каталог настроек, сертификат и формат сопряжения.
Старые поля настроек удалённого режима игнорируются. Для возврата системной Bluetooth-мыши через край требуется APK 0.7.8.
Старый APK сохраняет Bluetooth-ввод с возвратом горячей клавишей. Обновление APK поверх приложения сохраняет сопряжение,
если используется постоянная подпись: [инструкция](ANDROID_UPDATES.ru.md).

## Сенсорное управление

На телефоне включите службу Galaxy Bridge Wi-Fi в специальных возможностях.
После установки APK Android может потребовать разрешить ограниченные настройки
в сведениях о приложении. Разблокируйте телефон. Нажмите **Управлять телефоном**
или **Ctrl+Alt+F12**; повторное сочетание возвращает управление на ПК.

Левая кнопка — касание, удержание и перетаскивание. Для выделения текста сначала
удерживайте кнопку неподвижно до появления выделения, затем двигайте маркеры.
Правая кнопка — Назад, средняя — Недавние; колесо — свайп. Быстрый клик может
активировать доступный элемент под курсором; при отказе выполняется касание.
Стрелка приложения скрывается на время касания. Это сенсорное управление;
системного курсора Android и обычного наведения мыши оно не создаёт.

Выберите сторону телефона и включите **Вход через край экрана** при необходимости.
Возврат через край телефона учитывает направление движения, свежесть состояния
и удерживаемые кнопки. Горячая клавиша доступна независимо от переходов через край.
Скорость 0,25–4× и выбранная сторона сохраняются; изменение скорости останавливает
захват до следующего включения управления.

С Windows и APK **0.7.9**: **Ctrl + колёсико** выполняет жест двумя пальцами
для изменения масштаба PDF или изображения. Опция **Масштабировать колёсиком по Wi-Fi**
включает этот жест без Ctrl; по умолчанию отключена и сохраняется в настройках.
Просмотрщик должен поддерживать pinch-to-zoom. Быстрые однотипные события колеса
объединяются в ожидающей очереди; противоположные события могут отменять друг друга.

APK 0.7.9 подтверждает фактическое движение к краю на короткое время. Windows
сопоставляет подтверждение с последовательностью отправленного ввода, отвергает
старые захваты и немедленно сбрасывает подтверждение при движении внутрь телефона.
Задержка Wi-Fi и остановка мыши у границы больше не зависят от прежнего окна 200 мс.
Удерживаемые клавиши и кнопки по-прежнему блокируют переход. Для старого APK
сохраняется прежняя обработка края; масштабирование требует обновления APK.

С версии **0.7.10** Windows передаёт накопленное движение прямо из обработчика
мыши с интервалом не менее 8 мс; таймер передаёт остаток после остановки. Android
перемещает стрелку не чаще одного раза на кадр экрана. Проверки состояния телефона
и размеров экрана выполняются каждые 100 мс и перед действиями; при изменении
подтверждения выхода или кнопок обратная связь отправляется сразу. Координаты
кликов и жестов сохраняются без прогнозирования или анимационного смещения.

## Системная мышь по Bluetooth

Bluetooth запускается при открытии приложения. Требуется адаптер Windows с BLE
Peripheral. Готовый Bluetooth HID автоматически включает системную мышь;
без него работает курсор приложения по Wi-Fi. При ошибке используйте
**Подключить Bluetooth (тест)** для повторного запуска. На телефоне найдите ноутбук в настройках Bluetooth, подтвердите
сопряжение на обоих устройствах. Единственный подключённый телефон выбирается
автоматически; при нескольких выберите нужный в Galaxy Bridge. Готовность
определяется подписками на отчёты клавиатуры и мыши. Запись сопряжения без
подключения не меняет режим. При потере HID доступный Wi-Fi выбирается автоматически;
текущий захват прекращается, чтобы не перенести удержание кнопок на другой способ
ввода. Снова войдите на телефон обычным способом. После перезапуска приложения
может потребоваться **Подключить** в Bluetooth телефона.

Android обрабатывает системный курсор, наведение, пять кнопок, выделение,
перетаскивание и обе оси колеса. Раскладка физической клавиатуры выбирается на
телефоне. Для мыши специальные возможности не нужны. Для возврата на ПК используйте
**Ctrl+Alt+F12** либо край телефона с APK 0.7.8,
overlay-разрешением и подключением того же телефона по QR. Файлы и буфер идут по Wi-Fi.
Если Windows не сообщает BLE Peripheral, текущий BLE-режим недоступен;
используйте сенсорное управление по Wi-Fi. Это не проверка Classic Bluetooth HID,
который GlideX реализует собственным драйвером. Собственный Classic HID в Galaxy
Bridge ещё не реализован. [Анализ Windows GlideX](GLIDEX_WINDOWS.ru.md). [Подробности и ограничения](SYSTEM_MOUSE.ru.md).

## Общий текстовый буфер

В Windows включите **Общий текстовый буфер**, на телефоне — **Разрешить общий
буфер** и **Поверх других приложений**.

- ПК → телефон: новые копирования при активной связи автоматически попадают
  в системный буфер телефона. Вставляйте обычным способом или Ctrl+V.
- Телефон → ПК: копируйте при управлении телефоном, затем верните управление
  на ПК. Текст попадёт в буфер Windows. При копировании пальцем вне управления
  сначала войдите на телефон и вернитесь, либо используйте **Поделиться**.

Это чтение при возврате управления, а не наблюдение за всеми копированиями в фоне.
Android ограничивает доступ к буферу без фокуса. Приложение кратко создаёт
прозрачное окно 1×1 пиксель, получает фокус, читает текст и убирает окно. Если
фокус не получен за 750 мс, операция прекращается. Влияние этого перехода на
экранную клавиатуру и защищённые приложения ещё требует проверки на S25.

Поддерживаются обычный текст и ссылки до 16 КБ UTF-8. Форматирование, изображения,
файловые URI и очистка буфера не синхронизируются. При подключении существующий
буфер ПК не отправляется; полученный текст не возвращается обратно. Текст не
записывается в журналы или preferences. Новое копирование на ПК отменяет ожидаемый
ответ телефона. Повторный вход, выключение общего буфера, обрыв, закрытие,
блокировка или сон отменяют ожидающий приём. Прерванный обмен не воспроизводится.
При занятости буфера Windows выполняются до четырёх попыток.

## Файлы и завершение работы

Откройте **Окно файлов: отправка и приём**, перетащите файлы или нажмите отправку.
На телефоне выбирайте файлы либо используйте **Поделиться → Galaxy Bridge Wi-Fi**.
Требуются обычные файлы, до 2 ГБ каждый; папки не поддерживаются. Телефон сохраняет
их в Download/GalaxyBridge. Windows по умолчанию принимает в Downloads/GalaxyBridge;
папку и разрешение приёма можно изменить. Совпадение имени не перезаписывает файл.
При отмене или разрыве незавершённая передача удаляется; уже полученные файлы остаются.

Сворачивание прячет приложение в трей. Двойной щелчок открывает окно. Закрытие
окна или **Выход** завершает процесс, отпускает ввод и закрывает подключения.
Пауза и блокировка ПК останавливают захват; пауза не удаляет сопряжение.
Результаты автоматических проверок и список испытаний на устройствах —
в [TESTING.md](TESTING.md).
