# Wi-Fi без отладки — Windows 0.7.3 / Android 0.7.7

Иконка с монитором, телефоном и голубыми стрелками установлена в Windows
(включая окна и трей), Galaxy Bridge Wi-Fi и Galaxy Bridge Edge.
Для её появления обновите соответствующую программу после ручного workflow.

## Автоматический общий текстовый буфер

Обновите обе стороны: Windows **0.7.3** и Galaxy Bridge Wi-Fi **0.7.7**.
QR и сохранённое сопряжение остаются прежними; отладка не нужна.
На ПК включите **Общий текстовый буфер**. На телефоне один раз нажмите
**Разрешить общий буфер** и разрешите **Поверх других приложений**.
Для переходов курсора нужна включённая служба специальных возможностей.

- **ПК → телефон:** скопируйте текст при активном соединении. Он автоматически
  записывается в системный буфер телефона; вставляйте обычным способом или Ctrl+V
  при управлении телефоном с ПК.
- **Телефон → ПК:** скопируйте текст, управляя телефоном, затем верните курсор
  на ПК через край экрана или Ctrl+Alt+F12. Текст автоматически попадает в буфер
  Windows; вставляйте через Ctrl+V. Кнопки отправки и подтверждения не нужны.

Это чтение при возврате управления, а не постоянное наблюдение за каждым
копированием в фоне. При копировании пальцем вне управления сначала перейдите
курсором на телефон и вернитесь на ПК. Без перехода можно по-прежнему использовать
**Поделиться → Galaxy Bridge Wi-Fi** с подтверждением текста.
При подключении существующий буфер ПК не отправляется: синхронизируются новые
копирования, сделанные во время связи. Это сохраняет буфер телефона при подключении.

Android ограничивает чтение буфера приложением без фокуса. При возврате курсора
Galaxy Bridge кратко создаёт прозрачное окно размером 1×1 пиксель, получает фокус,
читает буфер и сразу убирает окно. Если фокус не получен за 750 мс, окно удаляется
и статус сообщает о недоступности. На S25 ещё нужно проверить влияние этого
короткого перехода фокуса на открытую экранную клавиатуру и защищённые приложения.

Поддерживаются обычный текст и ссылки до 16 КБ UTF-8. Изображения, файловые URI,
очистка удалённого буфера и богатое форматирование не синхронизируются.
Передаются только новые данные; полученный с ПК текст не пересылается обратно.
Текст не записывается в журнал или preferences. Передача использует существующий
канал TLS к сопряжённому устройству, с подтверждением записи в системный буфер.

Если во время получения ответа телефона вы скопировали новый текст на ПК,
ответ телефона отбрасывается. Новый вход на телефон, выключение общего буфера,
обрыв связи, закрытие режима, блокировка или сон ПК отменяют ожидающий приём.
Блокировка телефона запрещает чтение и запись общего буфера.
При занятости буфера Windows — до четырёх попыток; при отказе повторите копирование
или переход. Прерванный обмен не воспроизводится после переподключения.

Стороны согласуют поддержку автоматического обмена при подключении.
Новый Windows со старым APK сохраняет управление и прежний ручной приём;
новый APK со старым Windows предлагает обновить Windows, управление и файлы
продолжают работать. Новые команды старой стороне не отправляются.

## Обновление APK без удаления приложения

Android **0.7.4** использует постоянную подпись. Один раз добавьте ключ
в GitHub Secrets по [инструкции обновлений](ANDROID_UPDATES.ru.md).
Переход с прежних APK требует одной последней переустановки и QR-сопряжения.
Дальше открывайте новый GalaxyBridgeLan.apk и выбирайте **Обновить**:
настройки и сопряжение сохраняются. Номер APK увеличивается при каждом workflow.

## Сканер закрывается без подтверждения ноутбука

В Android **0.7.3** окно «Подключить ноутбук?» появляется прямо в сканере
после распознавания QR. Проверьте название и адрес и нажмите **Подключить**:
только после этого сканер закрывается и запускается соединение.
Запуск выполняется из сканера и не зависит от возврата результата на главный экран.
Кнопка **Сканировать заново** возвращает камеру. Распознанный QR сохраняется
при повороте экрана. Ошибка остановки камеры больше не прерывает подтверждение
или возврат результата. При ошибке запуска службы подтверждение остаётся открытым,
чтобы можно было повторить попытку; текст ошибки сохраняется на главном экране.

Обновите GalaxyBridgeLan.apk после ручного workflow; Windows 0.7.1 подходит.
Покажите новый QR в Windows и сканируйте его из Galaxy Bridge Wi-Fi.
Если потребуется удалить прежний APK из-за тестовой подписи, заново включите
специальные возможности для управления. Они не нужны для самого сопряжения.
Эта правка проверена компиляцией; устранение сбоя на S25 ещё нужно подтвердить.

## Нажатие мышью не выбирает файл

Если файл выбирается пальцем, но не мышью, обновите Android-компонент до **0.7.2**.
В Android 0.7.2 при коротком клике служба находила элемент под кончиком курсора в структуре
активного окна и вызывает его действие нажатия через специальные возможности.
Системное окно выбора файлов предоставляет такое действие для строк файлов.
В 0.7.7 этот путь остаётся для кликов, отпущенных до начала касания; остальные
нажатия передаются непрерывным сенсорным жестом. Проверка выбора файлов на S25
после этого изменения ещё требуется.
Если доступного элемента нет или действие отклонено, выполняется обычное касание.
Долгое нажатие и перетаскивание остаются жестами; небольшое движение мыши
учитывает системный порог касания. Слой курсора удаляется на время действия.

Обновите GalaxyBridgeLan.apk из нового ручного workflow; Windows 0.7.0/0.7.1 подходит.
После установки выключите и снова включите службу Galaxy Bridge Wi-Fi
в специальных возможностях, чтобы Android применил доступ к структуре окна.
Если потребуется удаление старого APK из-за тестовой подписи, заново выполните QR.
Если системное окно по-прежнему не реагирует на мышь, используйте кнопку
**Выбрать через файловое приложение…** и выберите доступное файловое приложение.
Некоторые приложения могут открывать тот же системный диалог. В этом случае
выберите файл пальцем на телефоне или отправьте его из «Моих файлов» через
**Поделиться → Galaxy Bridge Wi-Fi**. Системные ограничения доступа не отключаются.

Компиляция Android Java с API 35 и тесты классификации клика/перетаскивания
и поиска элемента проверяют исходники. Работа новой версии системного диалога
на S25 ещё требует проверки; устранение именно этого сбоя не подтверждено.

Этот режим использует **GalaxyBridgeLan.apk**, отдельное приложение для Android 13+.
GalaxyBridgeEdge.apk относится к прежнему режиму ADB и здесь не нужен.
Служба беспроводной отладки и настройки разработчика для нового режима не используются.

## Первое подключение

1. Получите Windows ZIP и **GalaxyBridgeLan-android** после ручного запуска
   Actions → Build Windows portable → Run workflow. Исходники сами сборку не запускают.
2. Установите GalaxyBridgeLan.apk на S25 и откройте **Galaxy Bridge Wi-Fi**.
3. Подключите телефон и ноутбук к одной доступной локальной сети.
4. В Galaxy Bridge на Windows нажмите **Wi-Fi без отладки (тест)**.
   Нажмите **Показать новый QR (2 минуты)**. Если показан адрес другой сетевой карты,
   выберите Wi-Fi-адрес в списке: код обновится.
5. На S25 нажмите **Сканировать QR**, разрешите камеру и подтвердите имя ноутбука.
   Сканируйте из этого приложения; QR из окна старого ADB-сопряжения не подходит.
6. Для управления откройте **Включить специальные возможности** на телефоне
   и включите службу Galaxy Bridge Wi-Fi. Это даёт ей право выполнять касания,
   глобальные действия и вводить текст в активное поле. В Android 0.7.2 служба
   также получает структуру активного окна для нажатия элемента под курсором.
   Код использует границы и доступные действия, не считывает текст элементов,
   не сохраняет его и не передаёт на ПК. Передача файлов работает и без этой службы.
7. Разрешите уведомления, чтобы видеть работающее соединение и кнопку остановки.
   В Windows разрешите Galaxy Bridge входящие соединения в брандмауэре для
   той сети, в которой используете программу: TCP 38271 и UDP 38272.
8. Разблокируйте S25. Нажмите **Управлять телефоном** или Ctrl+Alt+F12.

Если Android блокирует включение специальной возможности после установки APK,
откройте сведения о приложении и разрешите ограниченные настройки, если такой
пункт доступен. Затем вернитесь в специальные возможности.

## Если сканирование не завершилось сопряжением

В Windows 0.6.1 исправлен импорт сертификата для Schannel: прежний
EphemeralKeySet мог прерывать TLS до проверки QR. Сам сертификат и его
отпечаток сохраняются. Установленный Android-компонент 0.6.0 совместим:
для этой правки достаточно обновить Windows ZIP, APK переустанавливать не нужно.
После ручной сборки откройте новое окно Windows с версией **0.7.0**.

1. На Windows откройте **Wi-Fi без отладки**, выберите Wi-Fi IPv4-адрес
   и нажмите **Показать новый QR**. Оставьте это окно открытым.
2. Сканируйте кнопкой внутри **Galaxy Bridge Wi-Fi** на S25.
   После распознавания появляется **Подключить ноутбук?** — нажмите
   **Подключить**. Сканирование штатной камерой телефона не запускает сопряжение.
3. Под кодом Windows остаётся строка этапа подключения. Если она остаётся
   **Ожидаем соединение на ...**, TCP-запрос до программы не дошёл:
   проверьте правильный адрес, одну локальную сеть, отсутствие изоляции клиентов
   и разрешение приложения в брандмауэре используемого сетевого профиля.
4. Если появилась **Ошибка: TLS ...** или ошибка другого этапа, сохраните
   эту строку и статус приложения телефона. Они помогут определить следующий
   сбой. Не отправляйте сам QR: он содержит секрет сопряжения.
5. Для истёкшего/заменённого кода покажите новый QR и повторите подтверждение
   до истечения двух минут. Специальные возможности нужны для управления,
   но не для самого сопряжения.

Шифрование и проверка отпечатка не отключаются. Временный ключ TLS импортируется
в контейнер текущего пользователя Windows без PersistKeySet; при штатном
закрытии сертификата он удаляется. Постоянный PFX остаётся под защитой DPAPI.
Сертификат не добавляется в доверенные корневые центры Windows.

## Повторное подключение и смена Wi-Fi

Сопряжение сохраняется в закрытых данных приложений. После перехода телефона
и ноутбука в другую общую сеть телефон ищет сохранённый ноутбук и проверяет
его сертификат. Повторный QR не нужен, пока сопряжение не удалено.
При смене адреса используются широковещательные UDP-запросы; при отключении
связи повторные попытки идут с паузами 1, 2, 4, 8, 16, 30 секунд.

Окно нового режима Windows должно оставаться открытым (можно свернуть).
Отметьте **Открывать этот режим при запуске Galaxy Bridge**, чтобы приложение
сразу ожидало телефон. На S25 соединение поддерживает служба с уведомлением.
После принудительной остановки приложения или перезагрузки S25 откройте его
и нажмите **Подключиться к сохранённому ноутбуку**. При ограничениях фоновой
работы Samsung проверьте, что приложение не помещено в глубокий сон.
Автоматический запуск после загрузки Android в этой версии не реализован.

Сеть должна разрешать соединения между устройствами. Гостевая изоляция Wi-Fi,
разные несвязанные сети и маршрутизатор, блокирующий broadcast, могут мешать.
Если автообнаружение запрещено, покажите новый QR с текущим адресом; это не
обходит запрет сетевого доступа. IPv6 и работа через интернет пока не поддержаны.

## Управление

- **Скорость курсора телефона ×** регулируется от 0,25 до 4 с шагом 0,05.
  Значение 1 — обычная скорость; кнопка **Сбросить на 1×** возвращает его.
  Настройка сохраняется сразу и действует при следующем включении управления.
  При изменении скорости захват мыши прекращается: нажмите **Управлять телефоном**
  или Ctrl+Alt+F12 для проверки нового значения. Скорость курсора Windows не меняется.
- Курсор рисует приложение; он не является нативной USB/Bluetooth-мышью Android.
  В Android 0.6.1 вместо синей точки показана белая стрелка с чёрной обводкой,
  размер которой учитывает плотность экрана. Нажатие приходится на кончик стрелки.
- Левая кнопка начинает касание при нажатии, удерживает его до отпускания и
  передаёт движение во время перетаскивания. Быстрый клик, завершившийся до
  начала касания, может активировать элемент через специальные возможности.
  Небольшое движение в пределах порога Android не мешает долгому нажатию.
- Для выделения текста удерживайте левую кнопку неподвижно до появления
  выделения; затем перетаскивайте его маркеры. Обычное протягивание сразу после
  нажатия остаётся сенсорным свайпом. Это не нативная мышь Android.
- Во время касания стрелка скрывается: окно курсора удаляется перед вводом,
  чтобы защищённые элементы не отвергали касания. При отпускании она возвращается.
  При отключении или блокировке телефона удерживаемое касание завершается.
- Правая кнопка — Назад; средняя — Недавние. Колесо — вертикальный свайп.
- Есть кнопки Назад / Домой / Недавние в окне Windows.
- Текст вводится в выбранное поле через input connection службы. Работают раскладка
  Windows, Enter, Backspace, Delete, Tab, стрелки; Ctrl+V и Shift+Insert вставляют
  текст Windows, до 16 КБ UTF-8. Переключайте раскладку на ноутбуке до захвата.
- Ctrl+A/C/X вызывают действия редактора телефона. Общий буфер автоматически
  передаёт текст с ПК и читает текст телефона при возврате курсора на ПК.
  Постоянного наблюдения за фоновыми копированиями, изображений в буфере,
  автоповтора удерживаемых клавиш, dead keys,
  AltGr, медиа-клавиш и полного набора сочетаний нативной клавиатуры здесь нет.
- Расположение телефона выбирается в окне; вход через край включается отдельно.
  При входе курсор телефона ставится рядом с соответствующим краем.
  Возврат — через край в сторону ноутбука; резерв — Ctrl+Alt+F12.
- После потери связи, блокировки Windows или сна управление возвращается ноутбуку.
  При переподключении захват не включается сам; сначала отведите курсор от края.
- Заблокированный/выключенный экран S25 не управляется. Некоторые защищённые
  приложения могут не принимать жесты или ввод; это нужно проверить на устройстве.

## Файлы

Нажмите **Окно файлов: отправка и приём** в режиме Wi-Fi без отладки.
Откроется отдельное окно с большой зоной для перетаскивания. Можно оставить его
открытым рядом с Проводником, изменить размер и отключить **Поверх окон**.
Перетащите один или несколько обычных файлов в эту зону либо нажмите
**Выбрать файлы…**. При открытии окна управление мышью возвращается ноутбуку.
Статус показывает имя телефона, номер текущего файла и результат отправки;
кнопка **Отменить отправку** прерывает текущую очередь.

Пока нет соединения или идёт передача, выбор и приём новых файлов недоступны.
После восстановления связи окно снова принимает файлы. Закрытие только окна
отправки не отменяет начатую передачу; её статус остаётся в основном окне режима.
При закрытии самого режима передача отменяется и оба окна закрываются.
Также можно перетаскивать файлы в основное окно или нажать **Отправить файлы…**.
Все отправки сохраняются в **Download/GalaxyBridge**, без отдельной папки на партию.
Имена при совпадениях меняет Android MediaStore; существующий файл не перезаписывается.
Максимальный размер одного файла в тестовой версии — 2 ГБ. Папки не поддержаны.
Для обратной передачи нужны Windows и GalaxyBridgeLan.apk **0.7.0**.

### С телефона на ПК

1. В Windows оставьте открытым режим Wi-Fi без отладки. В **Окно файлов: отправка
   и приём** включите **Принимать файлы с сопряжённого телефона** (изначально включено).
   По умолчанию используется `%USERPROFILE%\Downloads\GalaxyBridge` — одна папка
   для всех отправок. **Изменить папку…** выбирает другой каталог; настройка сохраняется.
2. На S25 выберите фотографии/файлы в Галерее или «Моих файлах» и нажмите
   **Поделиться → Galaxy Bridge Wi-Fi**. Либо в самом Galaxy Bridge Wi-Fi
   нажмите **Отправить на ПК → Выбрать файлы…**.
3. Проверьте имя ноутбука и число файлов, затем нажмите **Отправить на ноутбук**.
   Разрешение даётся только выбранным файлам через Android content URI;
   доступа ко всему хранилищу приложение не запрашивает. Специальные возможности
   и отладка для файлов не нужны. Ссылки/текст без файлов не отправляются.
4. Пока соединение восстанавливается, выбранная очередь ждёт до 30 секунд.
   После начала передачи она привязана к текущему соединению; обрыв останавливает
   её. Старое Windows-приложение будет отклонено локально с предложением обновить его.
5. Прогресс и отмена доступны на S25 и в окне файлов Windows. **Открыть папку**
   открывает каталог приёма. Само окно файлов можно закрыть, оставив LAN-режим открытым.

Очередь ограничена 100 файлами, каждый — до 2 ГБ. Неизвестный заранее размер
потока поддерживается: вместо процентов отображается число переданных байтов.
Данные сначала пишутся в `.galaxybridge-<случайный-id>.part` в выбранной папке.
Только после проверки размера и SHA-256 файл получает окончательное имя.
Недопустимые для Windows символы заменяются; зарезервированные имена получают
префикс. При совпадении добавляется `(1)`, `(2)` и т. д.; существующие файлы
не перезаписываются. Полученные файлы не открываются автоматически.

Отмена, отключение приёма, обрыв, ошибка или 30 секунд без новых блоков удаляют
только текущий временный файл. Если Windows не разрешает удаление, статус сообщает
его имя. Готовые файлы сохраняются; при потере последнего подтверждения готовый
файл уже может существовать. Аварийное завершение Windows может оставить `.part`;
автоматическая очистка чужих/старых файлов не выполняется. Папки и возобновление
частично переданного файла в эту версию не входят.

Передача идёт последовательно блоками по 32 КБ, с подтверждениями и проверкой
SHA-256 всего файла. До завершения файл скрыт как незавершённый объект MediaStore.
При отмене или обычном обрыве удаляется только объект текущей незавершённой передачи;
готовые файлы сохраняются. При аварийном завершении процесса незавершённый объект
может остаться до очистки MediaStore. Прерванная очередь не повторяется автоматически.
Если файл завершился, но ответ потерялся, он может уже лежать в папке: проверьте
её перед повторной отправкой. Прогресс показывает количество файлов, не байты.

## Сопряжение и отключение

QR содержит одноразовый случайный секрет и отпечаток сертификата ноутбука.
Секрет живёт 2 минуты в памяти Windows, не записывается в журнал.
Телефон проверяет сертификат **до** отправки секрета; всё содержимое идёт в TLS.
После успешного сопряжения используется отдельный постоянный токен.
Сертификат и токен Windows защищены DPAPI текущего пользователя;
телефон хранит данные в закрытых preferences с отключённым резервным копированием.
Поддерживается один телефон и один ноутбук; новое сопряжение заменяет старое.

**Остановить / возобновить подключение** в Windows приостанавливает приём,
а **Остановить подключение** в приложении или уведомлении S25 выключает службу.
**Забыть телефон / ноутбук** удаляет соответствующее доверие; для следующего
подключения покажите новый QR. Удаление приложения Android также удалит сопряжение.

Начиная с Android 0.7.4 workflow восстанавливает постоянный ключ из GitHub
Secrets и проверяет отпечаток сертификата до сборки. После перехода с прежней
подписи новые APK устанавливаются как обновления с сохранением сопряжения.
Старое приложение Edge может оставаться установленным: пакеты различаются.

Новая стрелка появилась в GalaxyBridgeLan.apk 0.6.1 и включена в текущий APK.
Правила перехода и дальнейшего обновления — в [инструкции обновлений](ANDROID_UPDATES.ru.md).

Настройка скорости и окно отправки добавлены в Windows **0.6.2**. Для этих
изменений обновите Windows ZIP из нового ручного workflow; установленный
GalaxyBridgeLan.apk 0.6.0 или 0.6.1 подходит. Переустановка APK не требуется.

Для отправки **с телефона на ПК** обновите обе стороны до **0.7.0**.
Новый ручной workflow создаёт Windows ZIP и GalaxyBridgeLan-android.
В текущей версии переход с прежней тестовой подписи выполняется один раз;
последующие обновления сохраняют сопряжение и настройки.
Стрелка включена в новый APK. Старый APK может продолжать управление и приём
файлов с Windows 0.7.0, но кнопки обратной отправки в нём нет.
