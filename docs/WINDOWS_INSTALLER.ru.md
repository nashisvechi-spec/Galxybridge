# Установка Galaxy Bridge в Windows

Начиная с Windows 0.7.36 ручная сборка **Build Windows installer** создаёт два
артефакта: **GalaxyBridge-Windows-Setup** и **GalaxyBridgeLan-android**.

## Установка

1. В GitHub Actions откройте завершённую сборку и скачайте
   **GalaxyBridge-Windows-Setup**. GitHub упаковывает артефакт в ZIP.
2. Распакуйте его и запустите **GalaxyBridge-Setup-0.7.36-x64.exe**.
3. Пройдите мастер установки. Ярлык появится в меню «Пуск»; ярлык рабочего
   стола можно отключить в мастере. В конце можно сразу запустить программу.

Поддерживается 64-разрядная Windows 10 версии 2004 и новее, Windows 11.
По умолчанию установка выполняется для текущего пользователя в
`%LOCALAPPDATA%\Programs\GalaxyBridge`. Установщик не требует прав администратора.
Среда .NET входит в приложение, отдельно устанавливать её не требуется.
APK для телефона скачивается отдельно из **GalaxyBridgeLan-android**.

## Обновление и переход с портативной версии

Закройте Galaxy Bridge через меню значка в области уведомлений, затем запустите
новый установщик. Системный крестик главного окна может только свернуть
программу в трей. Установщик проверяет, что приложение закрыто, и обновляет
существующую установку. Повторно сканировать QR не нужно: настройки, сертификат
и сопряжение хранятся отдельно в `%LOCALAPPDATA%\GalaxyBridge`.

При переходе с портативной версии также закройте прежнюю копию и запустите
установщик под тем же пользователем Windows. Затем пользуйтесь новым ярлыком.
Старую портативную папку установщик не удаляет. Полученные файлы остаются в
выбранной папке приёма, по умолчанию — `Downloads\GalaxyBridge`.

## Удаление

Откройте «Параметры Windows → Приложения», найдите **Galaxy Bridge** и выберите
удаление. Закройте приложение, если мастер попросит. Программные файлы и ярлыки
удаляются; настройки, сопряжение и полученные файлы сохраняются.

## Сборка из исходников

Windows-публикация по-прежнему выполняется через `dotnet publish` с включённой
средой .NET. После добавления инструкций и лицензий запустите
`scripts/Build-WindowsInstaller.ps1`: он берёт версию из проекта и вызывает
компилятор Inno Setup 6. Результат записывается в `artifacts/installer`.
При необходимости путь к `ISCC.exe` передаётся параметром `-Compiler`.

Workflow проверяет установку, повторную установку, ярлык «Пуск», регистрацию
удаления и сохранность данных, затем публикует установщик. Исходная папка
публикации и портативный архив больше не выдаются в качестве Windows-артефакта.
