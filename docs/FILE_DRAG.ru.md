# Перетаскивание файлов · Windows / Android 0.7.13

Первый тестовый вариант: из карточки Galaxy Bridge на телефоне в рабочий стол
или папку Проводника. Управление мышью — **по Wi-Fi**. Bluetooth-мышь и
перетаскивание непосредственно из «Моих файлов» / «Галереи» пока не поддерживаются.

1. Обновите обе программы до 0.7.13. Для Android используйте APK с прежней
   подписью из существующего ручного workflow — обновление поверх установленного.
2. На ПК откройте окно файлов и включите «Принимать файлы с сопряжённого телефона».
3. На телефоне откройте «Отправить на ПК», выберите файлы и нажмите
   «Подготовить для перетаскивания на ПК». Дождитесь сообщения «Готово».
4. Включите управление телефоном мышью по Wi-Fi. Если тестовый Bluetooth-режим
   подключён, отключите его в Galaxy Bridge на ПК.
5. Зажмите синюю карточку левой кнопкой мыши. Потяните её к краю телефона со
   стороны ПК, удерживая кнопку. Если телефон настроен справа — тяните влево;
   слева — вправо; сверху — вниз; снизу — вверх.
6. Курсор вернётся на ПК с файлами. Наведите его на рабочий стол или нужную
   папку Проводника и отпустите кнопку. **Esc** отменяет перетаскивание.

Это копирование: оригиналы на телефоне сохраняются. При подготовке подборка
передаётся по существующему TLS-соединению, с проверкой размера и SHA-256.
В пользовательскую папку приёма она не записывается. Подборка ограничена
100 файлами и 2 ГБ суммарно. При повторном перетаскивании подготовьте её заново.

Windows получает обычный `FileDrop` через OLE и выбирает конечную папку.
Перетаскивание разрешено только при активном захвате Wi-Fi, зажатой левой
кнопке, движении наружу и совпадении поколения захвата. При отпускании кнопки
до возврата, блокировке ПК, разрыве соединения или отключении приёма операция
отменяется. Приложение не имитирует нажатие мыши на рабочем столе.

После успешной передачи в Windows временные исходники оставляются для
асинхронного копирования Проводником. Кэши старше 24 часов очищаются при
следующем запуске. При отмене, замене неподтверждённой подборки или разрыве
связи незадействованные подготовленные файлы удаляются сразу. Отмена на ПК
не удаляет исходники телефона и уже полученные обычным способом файлы.

## Проверка на устройствах

- Один маленький TXT, фото, PDF; затем несколько файлов и два одинаковых имени.
- Все четыре расположения телефона; рабочий стол, открытая папка и подкаталог.
- Отпустить кнопку до края: курсор остаётся на телефоне, файл не копируется.
- Esc после перехода: файл не появляется в целевой папке.
- Отключить сеть, выключить приём, заблокировать ПК во время перетаскивания.
- Большой файл: подготовка отдельно, плавность обычной мыши без изменений.
- Обновить APK поверх 0.7.11, проверить прежнюю подпись и сохранение сопряжения.

Компиляция и тесты протокола не заменяют эту проверку Windows/S25.
